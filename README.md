# Profile（プロフィール） [3周目]

CODEJUMP 入門編の「プロフィール」課題として制作しているWebサイトです。（基礎固めの3周目）

## 概要

ロードバイクが趣味の友人から頼まれた、自転車紹介のためのシンプルなプロフィールWebサイト（1ページ）を制作しています。

CODEJUMPの課題を通して、HTML・CSSの基礎構造やレイアウト設計、レスポンシブ対応について学習しています。

## コーディング仕様・学習内容

- **コンテンツ幅**: 960px（横パディング 4%）※メインビジュアルのみ全幅
- **メインビジュアル**: 全幅、高さ 600px 固定
- **About セクション**:
  - 画像の丸型切り抜き（`border-radius`）
  - 画像とテキストの横並び・中央寄せ配置
- **Bicycle セクション**:
  - 画像の両端揃え横並び配置
- **レスポンシブ対応**:
  - ブレークポイント 600px
  - レスポンシブ時はコンテンツを縦積みに配置
- **Git / GitHub**: バージョン管理

## 使用技術

- HTML5
- CSS3
- Git / GitHub
